# 南充嘉陵江城市漫游｜微信原生小程序 v2

这是与当前 H5/运营后台统一 API 的原生微信小程序工程，不是 WebView 套壳。

## 导入
微信开发者工具 → 导入 `nanchong-city-tour-weapp/`。

`project.config.json` 当前为联调占位 AppID；正式上线替换为主体 AppID，并配置服务器域名。

## 四个一级入口
- 首页
- 实时
- 漫游
- 我的

额外页面包括线路、站点、City Walk、地点、收藏、登录、会员、权益、活动、消息、客服、乘车指南与隐私。

## 数据源
`services/config.ts` 只配置 API Base URL；页面不内置商家/车辆模拟数据。

## 当前联调边界
微信手机号授权、公交实时数据、乘车码和真实地图只有在外部配置完成后启用。联调测试手机号验证码不是正式身份认证。
