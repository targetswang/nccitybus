# 两端对齐矩阵

两端共用 API 内容版本、地点 ID、路线 ID、过滤规则、地图图层规范和设计参数；原生组件表现不宣称像素级相同。

| 产品页面/动作 | H5 | 原生小程序 | 当前验证 |
|---|---|---|---|
| 首页 / 大小 Banner / 快捷入口 | 独立 React 页面 | WXML/WXSS | H5 DOM 回归；原生静态与逻辑测试 |
| 实时 / 五类图层 | 腾讯 GL 地图适配 | 原生 map | marker 数据集切换已测；真实地图服务/真机未测 |
| 漫游 / 路线或地点 | 状态保留 | switchTab + 本页状态 | 同版完整内容、类别/节点筛选 |
| 线路 / 全部节点 / 节点详情 | 独立页面 | 独立页面 | 未知 ID 不回退首项 |
| 四条 City Walk / 九个节点 | 完整正文/提示/引用 | 同一 API 正文 | 引用完整校验；不再截断为另一套数据 |
| 地点详情 | 地址/介绍/收藏 | 同一字段 | 无坐标不提供假的导航 |
| 导航 | 官方腾讯地图 URI | wx.openLocation | 只接受已验证 GCJ02；外部地图未真机验收 |
| 讲解 | 有音频用 audio，否则阅读 | 有音频用 InnerAudioContext，否则阅读 | 无音频不显示“正在播放” |
| 收藏 | 本机匿名 | 本机匿名 + 配置后微信账号同步 | Node 账号隔离；离线 H5 测试使用受控存储 |
| 登录 | 无微信 OAuth | wx.login → 服务端 session | 接口逻辑已测，微信主体联调未测 |
| 底栏 | 详情页常驻 | tabBar + 详情 bottom-nav | 不再 reLaunch 销毁页面栈 |
| 刷码 | 解释需在微信打开 | 真实目标小程序 adapter | AppID/Path 未提供，不假跳转成功 |
| 我的 / 权益 / 隐私 / 指南 | 同类入口 | 同类入口 | 无游客运营后台、无点击次数凑数 |

## 有意保留的平台差异

H5 是匿名网页入口，没有为满足外观一致而伪造 wx.login。原生地图“我的位置”由用户点击才请求位置；当前 H5 不主动获取用户位置。内容可阅读，不依赖定位授权。

两端的地图 marker、实时状态来源一致；原生实机的手势、底栏/安全区、权限和 SDK 兼容性必须在开发者工具及 iOS/Android 验证。浏览器截图不是原生截图。

## 生产素材缺口

参考内容21个地点保留历史候选来源；本版未把未经确认的外部热链/第三方免费代理当作正式图片。`cover=null` 是明确缺口而非加载成功。当前卡片有设计占位；自有媒体导入与自动裁剪流程已实现，但正式实景图、音频和逐项真实性/授权仍待核验。
