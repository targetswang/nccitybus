# H5、小程序与运营后台一致性

比对对象是同一提交的 `apps/h5`、`apps/weapp-native` 和 `apps/admin`，不是此前保留的旧小程序。只有三端连接同一目标后端、使用相同已发布内容版本时，才能据此验收线上一致性。当前没有已核验的线上部署或真机结论。

最新逐页标准、修复范围和待验收项见 [页面功能验收表](PAGE_PARITY_ACCEPTANCE.md)。此前自动测试只覆盖部分业务链路，不证明所有页面相同。

## 业务对应

| 业务 | H5 与正式小程序 | 后台 / 服务端 | 验证依据 |
|---|---|---|---|
| 首页标题、精选路线、Banner、公告 | 读取同一发布内容；共用 homeContent 排序和数量规则 | 首页和内容草稿，审核后显式发布 | client-parity 的真实 HTTP 发布及原生首页处理器测试 |
| 地点、攻略、站点、指南 | 相同业务 ID 与正文；不存在的详情不替换成首条 | 规范化内容表、revision、发布版本 | 契约和引用测试；详情仍需两端 UI 验收 |
| 实时公交、五类地图图层 | 共用 mapScene / transitMessage；每 10 秒更新；过期车辆不绘制；官方公交站不以旅游节点替代 | Transit Worker 发布线路及车辆快照 | client-native 与 client-parity；实际地图 SDK 待真机 |
| 地图导航 | 同一 GCJ02 合法性校验和公交站匹配 | 无有效坐标不返回替代位置 | 纯函数及原生图层测试 |
| 登录、退出、账户 | 验证响应 token；注销调用服务端 | 统一用户与会话；user/admin audience 分离 | review-client-session 真实 HTTP 测试 |
| 收藏 | 匿名本机收藏；登录后服务端账户收藏 | 同一 user_favorites | 用户/API 回归；匿名收藏仅在本设备保存 |
| 会员加入 / 退出 | 展示规则与有效期；同一 join / leaveMembership | 当前发布方案，记录状态 active / withdrawn | 原生页面处理器与 H5 请求跨端回读 |
| 活动报名 / 取消 | 详情按 ID 筛选，同一 register / cancelRegistration | 名额、开放条件及取消状态由服务端判断 | 原生页面处理器与 H5 请求跨端回读 |
| 权益领取 / 使用说明 | 同一 claim / openBenefit；查看不等于核销 | 领取记录与规则快照 | 用户业务回归；外部权益履约待现场 |
| 反馈、隐私请求、消息 | 统一分类和记录；客服公开回复回读 | 客服处理工单、发消息；内部备注不外泄 | client-parity 原生反馈→后台回复→两端读取 |
| 内容下架与并发编辑 | 只读取完整发布快照 | 下架保留、乐观锁、审核版本校验 | review-regressions R3～R5 |
| 讲解 | 有音频时播放，否则阅读正文 | 相同 audioUrl / narration | 正式原生组件构建检查；音频服务及设备待验收 |

H5 的 `event/:id`、`benefit/:id` 分别对应小程序 `events/index?id=…`、`rights/index?id=…`，因此 H5 路由数和小程序 19 页数量不必相等。

## 发布及刷新时机

后台编辑保存为草稿，游客版本不变。审核人员提供依据并确认精确草稿版本，发布成功才切换 active release；失败保留上一版。媒体授权校验独立保留。不得用测试参考内容覆盖已审核版本。

两端普通内容页每 5 分钟刷新，会员/活动/权益内容每 30 秒刷新；进入页面和手动刷新也会请求当前版本。小程序仅合并同时进行的内容请求，不无限期缓存旧发布内容。站点和实时页每 10 秒更新，离开页面停止轮询。已打开页面不是毫秒级推送，现场验收须先刷新，再比较 `/api/v1/content.version`。

## 平台差异

- H5 使用浏览器路由和腾讯地图适配；原生使用页面栈、自定义底栏和微信 map。底栏 reLaunch 会重建页面，本轮增加会话内筛选、图层、线路、地图视角和滚动位置恢复；不缓存私人账户记录。
- H5 用验证码登录；原生额外支持用户主动授权的微信手机号登录。两者最终由后端按身份关联用户。
- H5 外部权益链接可在浏览器打开；原生显示使用说明并允许主动复制 HTTPS 合作方链接，不假定已配置任意 web-view 业务域名。
- 乘车码原生跳转需要实际目标 AppID/Path；H5 给出微信使用提示。缺配置不能标记跳转验收成功。
- 原生 WXSS 独立维护；共享业务规则不等于像素级相同。

## 现场验收

使用同一部署提交和后端：编辑首页/POI→确认两端仍见旧版→审核发布→刷新并核对新版本；用同一手机号分别登录→收藏、加入/退出会员、报名/取消、领取权益、提交反馈→后台查记录并回复→两端回读。随后按 [微信真机验收](WECHAT_DEVICE_ACCEPTANCE.md) 完成 iOS/Android、音频、授权、乘车码和网络失败重试。Node VM 执行原生处理器不等于微信官方编译或设备验收。
