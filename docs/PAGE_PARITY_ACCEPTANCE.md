# 页面功能一致性验收表

基线：03149bc 的逐页复审。该基线存在权益按钮禁用、反馈重复提交、地图标记未绑定、路线图片缺失、活动状态差异及页面状态丢失，不能以此前 87 项测试作为全部页面一致的证明。

本轮修改以同一发布版本、同一账户能够完成同一业务动作为标准。下表“自动覆盖”仅描述检查范围，不替代官方微信工具与现场验收。

| 页面 | 内容 / 动作标准 | 本轮修改及自动覆盖 |
|---|---|---|
| 首页 | 标题、精选、Banner 图片、公告、乘车码及出发前入口 | 共用 homeContent；补齐双方遗漏的图片/入口；发布回读及浏览器交互 |
| 漫游 / 路线列表 | 玩法/地点切换、类别与站点筛选、图片、详情跳转 | 补齐小程序 coverPoiId 图片映射、选中站名；重建后恢复筛选 |
| 地图 | 五类图层、线路选择、标记/列表跳转、地图视角 | 标记与列表共用详情处理器；刷新保留用户视角；处理器回归 |
| 线路 / 站点列表 | 动态站点数量、文旅节点与公交停靠区分 | 移除固定五站及固定闭环承诺；实际顺序以公交数据为准 |
| 站点详情 | 已匹配公交站导航、周边地点、实时入口 | 双端 10 秒刷新；未核验坐标不给导航入口 |
| 攻略详情 | 封面、步骤图、正文、停留/步行提示、导航、讲解 | 补齐小程序封面与步骤图片、H5 步行提示；图片字段回归 |
| 地点详情 | 地址、营业/价格缺失提示、导航、讲解、收藏、关联站点 | 补齐提示与导航可用状态；收藏和会话往返回归 |
| 我的 | 收藏数量、站点入口、服务入口、刷新、退出 | 动态站点数与匿名收藏数；移除固定“测试账户”文案 |
| 收藏 | 已保存内容与失效收藏提示 | 小程序补齐不可用数量；不删除原收藏标识 |
| 会员 | 规则、开放状态、加入/退出、有效期 | 共用服务端可用状态、日期格式；提交锁及跨端账户回读 |
| 活动 | 规则、取消原因、开放/结束/满额状态、报名/取消 | 两端禁用相同状态；服务端最终校验；浏览器与处理器回归 |
| 权益 | 规则、可领取原因、领取记录、有效期、使用说明 | 补齐服务端状态；小程序支持主动复制 HTTPS 合作方链接 |
| 消息 | 标题、正文、时间、已读状态、标记已读 | 同一日期格式；小程序补齐时间/已读标识；实际 API 回归 |
| 客服 / 隐私请求 | 统一分类、提交、记录时间、公开回复 | 同一分类列表、提交锁和幂等键；连点/重试/冲突回归 |
| 指南 / 隐私 | 同一发布正文、内容与图片说明、定位说明 | 补齐双方缺失说明；刷新与错误重试入口 |
| 登录 | 同一账户与用户权限；手机号授权和短信方式按平台实现 | 保留已完成 token / 注销测试；真实微信授权待现场 |

## 状态与刷新规则

- `/content.version` 仍标识发布内容；会员、活动、权益的 `availability` 和 `availabilityReason` 在请求时按开放时间、取消状态和名额计算。响应 no-store，不能因 version 不变而缓存旧名额。
- 服务内容页 30 秒刷新，普通内容页 5 分钟刷新；站点及实时数据 10 秒更新。进入页面及手动刷新可提前读取当前数据。网络耗时会影响实际完成时间，提交仍由后端再次判断。
- 小程序底栏仍使用原生页面导航；在同一应用会话内恢复白名单中的筛选、图层、线路、地图中心/缩放及滚动位置，不保存账户数据到页面状态缓存。重启应用不承诺恢复。
- `ticket/privacy` 同一用户、动作、幂等键的相同内容只生成一条工单；不同内容复用键返回 409。网络失败重试复用键，成功后新的提交使用新键。旧客户端无键请求兼容但不具备此保护。

## 平台能力对应

H5 地图导航使用地图 URI，小程序使用 wx.openLocation；H5 音频使用浏览器播放器，小程序使用 InnerAudioContext。H5 可打开合作方链接，小程序提供说明及复制 HTTPS 链接；尚未配置业务域名时不声称能任意打开 web-view。乘车码跳转及微信手机号授权依赖真实微信配置。

## 测试与现场证据

- `page-parity.test.mjs`：新增页面行为、幂等、状态、图片字段和记录回归。
- `client-parity.test.mjs`：后台发布→实际两端 HTTP 适配→原生首页，会员/活动/客服往返。
- `tests/browser/parity.py`：Chromium 390 / 1440 宽度，真实本地 HTTP API，检查图片、筛选保留、活动禁用、权益领取、反馈及 JS 错误。CI 保存报告与截图；测试素材为隔离夹具，不是正式业务素材。
- 微信官方编译、iOS/Android 真机：尚未执行。需要按本表逐行完成截图/操作证据和后台回读，才可认定现场页面验收完成。

本轮代码修改完成不等于已同步部署线上版本。现场必须记录三端部署 commit、API 地址和内容 version。
