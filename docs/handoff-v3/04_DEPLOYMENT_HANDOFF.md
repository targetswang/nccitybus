## 生产前必须配置

1. 正式小程序 AppID / Secret
2. 微信 request 合法域名
3. H5 / 后台短信服务
4. 腾讯地图或高德地图正式 Key
5. 公交 IVY HTTP / MQTT
6. 正式线路 / 跑法 / 站牌 / 车辆映射
7. 微信乘车码 AppID / Path / 白名单
8. 图片来源及使用范围审核
9. 生产事务数据库（启用有限名额权益/活动时）
10. 微信开发者工具、iOS / Android 真机回归

## AI 运营助手

当前支持平台模型；可切换 DeepSeek / Kimi。

外部模型密钥只能存服务端 Secret：
- `DEEPSEEK_API_KEY`
- `KIMI_API_KEY`

助手只允许：
- 查询
- 形成草稿提案

提案必须人工确认才保存为业务草稿，不能直接发布。

## 有限库存

当前 AppDeploy KV 预览数据库没有事务型库存扣减，因此：
- 有限数量权益不能正式发布
- 有限名额报名不能正式发布

生产启用前必须换成具备事务/原子扣减能力的数据层。

## 验收最低范围

- 后台登录和权限拒绝
- 内容新增/编辑/审核/发布/回滚
- 图片抓取、裁剪、证据、发布
- CSV/XLSX 导入
- AI 查询/提案/确认
- H5 与小程序读取同一个内容版本
- 游客登录/收藏/会员/权益/活动/客服
- 统计故障不阻断业务
- 公交未接入不显示模拟车或 ETA
- 微信真机
- 公交实车
